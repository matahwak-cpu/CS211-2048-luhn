# Luhn Validation Plan

Create a separate C++17 console program that:
- Reads input as a string to preserve leading zeros.
- Accepts exactly 16 digits and rejects malformed input.
- Uses separate input-validation and checkLuhn functions.
- Doubles every second digit starting from the right,
  leaving the rightmost digit unchanged.
- Subtracts 9 from doubled values greater than 9.
- Checks whether the total is divisible by 10.
- Allows repeated checks and a clear exit option.

Implementation and testing are not yet complete.
